# Student Task Management System

A simple task manager built using HTML, CSS, and JavaScript.

## Team Members

- Student 1: Rumaan Ahmed
- Student 2: Khadija Mustafa

## Project Overview

The Student Task Manager is a simple web-based project designed to help university students organize their tasks and stay productive.

The project is being developed collaboratively using Git and GitHub. Git is used to track changes and maintain the project history, while GitHub is used for collaboration, branches, Pull Requests, code reviews, and project management.

## Features Implemented So Far

### Task Input Form

A task input form has been added to the project. It includes:

- Task Title field
- Task Description field
- Add button

The form provides a simple interface for entering task information.

### CSS Styling

CSS styling improvements have also been added to make the application more organized and visually appealing.

The styling includes:

- Improved page layout
- Styled input fields
- Improved button appearance
- Better task card presentation
- Responsive layout improvements

## Project Files

The project currently contains the following main files:
